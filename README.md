A single-line, one-star review written in the voice of a house cat about its human, for the make.fun competition "Make the AI Judge Laugh: Cat Reviews Its Human".

`main.py` (Python stdlib only) writes a single original line to
`entry.txt` in the directory given by `MAKEFUN_OUTPUT_DIR` (default `/output`).

The line:

> One star. He refills my bowl on time, then sits on my warm laptop all day and calls ME needy. I pay rent in purrs; he pays in betrayal.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
